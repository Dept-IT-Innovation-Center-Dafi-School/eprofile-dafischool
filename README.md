# e-profile-dafischool

`e-profile-dafischool` adalah sistem brosur digital (Digital Menu) yang dirancang untuk membantu tim marketing Dafi School Makassar dalam mempresentasikan profil sekolah, program unggulan, dan informasi pendaftaran secara interaktif dan modern kepada calon orang tua siswa.

## 🎯 Tujuan
Sistem ini berfungsi sebagai alat bantu penjualan (sales kit) di lapangan yang memudahkan penyampaian informasi sekolah secara cepat, rapi, dan mudah diakses melalui perangkat mobile, layaknya melihat daftar menu di kafe.

## 🚀 Fitur Utama
- **Interactive Catalog**: Navigasi program sekolah yang mudah dipahami.
- **Mobile-First Design**: Tampilan yang dioptimalkan untuk kenyamanan di HP/Tablet.
- **Dynamic Content**: Memudahkan update informasi program atau biaya tanpa perlu cetak ulang brosur.
- **Call-to-Action**: Tombol pintas ke WhatsApp atau formulir pendaftaran.
